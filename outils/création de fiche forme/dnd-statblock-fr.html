            Capacités :

            Utilisez _ pour l'italique et ** pour le gras. Pour les listes de sorts, utilisez > pour une indentation inversée.

            [MON] : affiche le nom du monstre.
            [CHA] : affiche le modificateur de Charisme du monstre.
            [3D6] : calcule 3d6.
            [STR ATK] : calcule le modificateur du jet d'attaque du monstre pour une attaque basée sur la Force.
            [DEX 2D8] : calcule le jet de dégâts d'une attaque basée sur la Dextérité avec des dés de dégâts 2d8.
            [WIS SAVE] : calcule le DD de sauvegarde basé sur la Sagesse du monstre.
            [3D6 + 1], [STR ATK - 2], [WIS SAVE + 3] : ajoute un modificateur aux valeurs données.
